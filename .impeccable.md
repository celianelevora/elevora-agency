# Impeccable — Contexte projet

_Projet : **Elevora** — site marketing de l'agence digitale (Nantes). Stack : Next.js 14.2 (App Router, SSG), TypeScript strict, Tailwind + shadcn/ui, GSAP/ScrollTrigger + Framer Motion, Lenis._

## Design Context

### Users
Prospects francophones d'une agence web : **indépendants, artisans, commerçants, PME** qui évaluent un partenaire pour créer leur site (vitrine, e-commerce, landing, application) ou un CRM/outil de gestion sur mesure. Ils naviguent sur desktop **et** mobile, en journée, et jugent en quelques secondes la **crédibilité et le goût** de l'agence. Le job : « trouver une agence qui maîtrise vraiment et dont le rendu me ressemblera ». L'interface doit évoquer **confiance, désir, raffinement** — et donner envie de remplir le formulaire « Démarrer un projet ».

### Brand Personality
Trois mots : **éditorial · raffiné · cinématographique**. Voix française, posée, sûre d'elle sans arrogance — « un seul interlocuteur, du devis à la mise en ligne ». Le site est lui-même la preuve du savoir-faire : chaque détail (curseur custom, séquence canvas au scroll, transitions) démontre la qualité vendue.

### Aesthetic Direction
Direction **éditoriale / luxe discret, cinématographique**. Base claire **crème `#EAE9EE`** rythmée de sections **Nuit `#1A1A2E`** dramatiques (le gris de fond cale exactement les images de transition). Accent **Framboise `#C9266A`** rare et précis ; **Bleu Klein `#1B4F8A`** comme couleur primaire/structure.
- **Thème** : majoritairement clair (crème) avec scènes sombres immersives — choisi car les prospects évaluent en journée et veulent élégance + lisibilité, pas une UI sombre « tech ».
- **Anti-références** : template SaaS générique, « AI slop » (cyan-sur-sombre, gradient text, grilles de cartes identiques, glassmorphism décoratif, métriques héroïques).

### Typographie (charte — exception assumée)
- **Titres** : **Cochin** (Linotype, présente sur Mac/iOS) → fallback web **Cormorant Garamond** via `next/font` self-hosté. _Choix de marque délibéré_ (Cochin = identité française historique ; Cormorant en est le substitut le plus fidèle), pas un réflexe — Cormorant n'est conservée que comme fallback de Cochin.
- **Corps** : **Satoshi** (Fontshare) — remplace Roboto (banni). `--sans`.
- Échelle fluide `clamp()` sur les titres, hiérarchie marquée, capitales réservées aux eyebrows/labels.

### Design Principles
1. **L'éditorial d'abord** — la typographie est le héros ; composition asymétrique, alignement à gauche, respiration généreuse, jamais tout centré.
2. **Le mouvement raconte** — scroll-canvas, reveals staggered (`StaggerText`/`BlurFade`), curseur custom ; motion au service du sens, easing exponentiel, jamais de bounce, `transform`/`opacity` only, respect de `prefers-reduced-motion`.
3. **Charte stricte, accent rare** — Klein/Framboise/Nuit/crème via tokens (`--klein`, `--pink`, `--night`, `--cream`) ; framboise ≈ 10% du poids visuel ; jamais de gris sur fond coloré, ni de pur noir/blanc.
4. **Accessibilité WCAG 2.2 AA non négociable** — contraste, focus visibles, navigation clavier, formulaires labellisés (`htmlFor`/`id`), `role="alert"`/`status`, menu burger mobile, skip-link.
5. **Zéro AI slop** — pas de gradient text, pas de `border-left` accent, pas de grilles de cartes génériques, pas de glassmorphism gratuit ; chaque ornement renforce la marque.

### Contraintes techniques
SSG/Lighthouse > 90 mobile & desktop · images via `next/image` · polices `next/font` ou Fontshare uniquement · sécurité (CSP, rate-limit, sanitisation) · footer « Site conçu par Elevora Agency ».
